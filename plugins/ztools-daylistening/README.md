# 白噪音聆听 · DayListening

> 不必追赶每一种声音，安静也是一种抵达。

白噪音聆听是一款面向 **Windows / ZTools** 的环境声与背景音乐插件。用轻雨、微风、林间和海洋的声音，搭配一首舒缓音乐，为阅读、工作和休息留出安静的空间。


## 功能

- **32 个音源**：24 种自然环境与柔和底噪、8 首背景音乐，所需音频随包提供，日常播放无需外部音频服务。
- **独立混音**：环境声可以叠加，分别调节音量；背景音乐每次播放一首，切换时替换上一首。
- **柔和循环**：背景音乐在结尾约 2.5 秒渐隐，循环回开头后约 2.5 秒渐入，减轻首尾衔接的突兀感。
- **8 组宁静预设**：每组包含一首背景音乐，一键载入低音量组合，也可保存和删除自己的混音方案。自定义预设需包含一首单轨音量大于零的音乐；历史无音乐预设载入时会补入低音量的“睡莲”。
- **专注倒计时**：25 / 45 / 60 / 5 / 15 分钟，支持暂停、重置和结束提示；可设置结束时暂停声音。
- **暂停与恢复**：暂停保留当前组合、音量与本次播放位置；重新启动插件后恢复选择，点击播放才发声。
- **主音量与静音**：主音量、单轨音量和静音独立控制，提示音遵循静音设置。
- **后台播放设置**：在宿主支持的生命周期内，可选择离开插件页面后继续播放或暂停。
- **紧凑布局与 5 种主题**：常规窗口请求高度 580px，窄窗口 520px；屏幕空间较小时允许滚动，避免截断内容。

## 音源分类

| 分类 | 音源 |
| --- | --- |
| 自然 | 森林、海浪、溪流、海岛、夜晚、微风、洞穴、瀑布 |
| 雨声与底色 | 毛毛雨、窗边雨、帐篷雨、雨伞、森林雨、粉噪音、棕噪音、柔白噪 |
| 生灵低语 | 鸟鸣、蟋蟀、狼嚎、猫头鹰、林鸟、海鸥、蛙鸣、深海鲸鱼 |
| 宁静音乐 | 月下独白、晨雾微光、雨后余音、舒缓氛围、冥想钢琴、流动幽境、柔光漫游、睡莲 |

粉噪音、棕噪音和柔白噪为合成声音。音乐是普通背景配乐，不宣称医疗或疗愈效果。第三方作品原名、作者、来源和许可见 [第三方素材说明](THIRD_PARTY_NOTICES.md)。
