## 1.0.0 - 2026-09-10
- **三引擎深度占用检测**：结合运行中进程镜像扫描、NT 内核句柄扫描与 Restart Manager API，毫秒级精准定位文件与文件夹占用源；
- **安全移至回收站**：解除占用后支持将文件/文件夹安全移入系统回收站，避免硬删除误删数据并支持随时还原；
- **进程级精细控制**：提供占用进程右键菜单（查看结构化详情、打开程序位置、无损释放句柄、强制结束进程）与双击快速定位；
- **多维度解锁后动作**：支持一键解锁、解锁并移至回收站、解锁并重命名、解锁并移动以及资源管理器定位；
- **批量处理与便捷导入**：支持多文件拖拽、剪贴板路径粘贴、批量勾选及一键「全部解锁」「全部移至回收站」；
- **现代主题 UI 适配**：完整适配系统深色（Dark）与浅色（Light）模式，优化明亮模式下按钮与快捷键提示的高对比度视觉体验。
